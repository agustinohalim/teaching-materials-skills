# Templat Daftar Kendali Dokumen Perangkat Pembelajaran

Salin ke akar folder perangkat ajar sebagai `Daftar_Kendali_Dokumen_Perangkat_Pembelajaran.md`,
lalu isi. Bagian yang nilainya belum diketahui **dibiarkan kosong**, tidak ditebak.

```markdown
# Daftar Kendali Dokumen Perangkat Pembelajaran

Program Studi: …            Semester: …            Tahun Akademik: …
Disusun: …                  Revisi terakhir: …

## A. Aturan pokok

RPS adalah acuan tunggal. Arah penurunan hanya satu:
Kurikulum/Borang → RPS → {Kontrak Kuliah, Lembar Tugas, Modul, Kerangka Buku Ajar} → {Slide, Kunci Jawaban}.
Bila dokumen turunan memperlihatkan kekeliruan RPS, pekerjaan dihentikan dan dilaporkan;
dokumen turunan tidak ditambal.

## B. Butir terkunci

Mengubah butir di bawah menuntut revisi RPS bernomor.

| 5 | Bobot CPMK | |

| 7 | Susunan pertemuan (termasuk UTS/UAS) | |

|---|---|---|---|---|

## F. Urutan kerja menyusun dokumen baru

1. Periksa RPS — cocokkan materi pertemuan dengan matriks D.
2. Susun dokumen persis pada materi itu.
3. Perbarui kerangka buku ajar (sub-bab, halaman, daftar gambar).
4. Susun slide dari kerangka slide modul.
5. Jangan menyentuh RPS dan kontrak kuliah.
```

## Mengapa bagian C penting

Nilai administratif yang dikarang — gelar, NUPTK, kode dokumen — lolos dengan mudah karena
terlihat wajar, lalu tercetak di dokumen yang ditandatangani. Kolom kosong jujur; kolom terisi
tebakan tidak.
